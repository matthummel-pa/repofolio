## Getting help

| I want to… | Do this |
|------------|---------|
| Report a bug | Open a **Bug report** issue (Issues → New issue) |
| Request a feature | Open a **Feature request** issue |
| Ask a usage question | Start a **GitHub Discussion** (or open a "question" issue) |
| Report a security problem | Email **security@matthummel.com** — do **not** open a public issue |

## Before you file a bug

Please include:

1. WordPress version, PHP version, and Repofolio version.
2. Active theme and whether the issue persists with a default theme.
3. Steps to reproduce and what you expected vs. what happened.
4. Any message from **Settings → Repofolio**, and relevant lines from your `wp-content/debug.log` (see [ERROR-LOG.md](docs/ERROR-LOG.md) for how to enable it).
5. Whether "Clear cached GitHub data" (on the settings page) changes anything.

## Response times

This is a community project maintained on a best‑effort basis. Bugs affecting security or data loss are prioritized. Typical first response: within a few business days.
