# About Repofolio

**Repofolio turns your GitHub repositories and website projects into a living portfolio inside WordPress.**

Developers and agencies keep their best work in two places: open‑source repositories on GitHub and client websites they've shipped. Showing both on a personal or studio site usually means copy‑pasting stats that go stale the moment a repo gets a new star or release. Repofolio removes the busywork — it connects to GitHub with OAuth, pulls live repository data on a schedule, and displays exactly the fields you choose, while also giving you polished patterns to write up regular web‑design projects as case studies.

## What it does

- **Live GitHub grid.** A block that renders your repositories as cards with the details you pick — description, topics, language bar, stars, forks, license, latest release, and more. Data refreshes on GitHub's cadence (six‑hour cache), so it's always current without manual edits.
- **Login with GitHub.** A proper OAuth App flow — connect once, no tokens to hand‑copy. Authenticated requests also lift your API limit to 5,000/hour.
- **Choose what to show.** Global display toggles plus per‑block overrides, so a homepage teaser and a full projects page can show different levels of detail from the same source.
- **Website project case studies.** A dedicated Website Projects post type and a library of block patterns (hero, results, gallery, testimonial, CTA) for the client work that doesn't live in a repo.

## Who it's for

Freelance developers, design studios, and technical founders who want one portfolio that speaks to both engineers (repos, languages, releases) and clients (outcomes, case studies) — without maintaining two systems.

## Design principles

1. **Live, not stale.** Pull from the source of truth; cache politely.
2. **You choose the story.** Every field is a toggle; nothing is forced on the page.
3. **Secure by default.** Secrets encrypted, least‑privilege scopes, escape everything.
4. **Drop‑in.** No build step, no framework lock‑in — install the zip and go.
