What it does

Everything you need to show your code and your client work in one place.

◆

Login with GitHub

A real OAuth "Connect with GitHub" button. No tokens to hand-copy, and 5,000 API requests/hour.

▤

Live repo grid

A block that renders your repositories as cards with the details you choose — refreshed on GitHub's cadence.

⚙

Choose what to show

Toggle description, topics, language bar, stars, forks, license, latest release, and more — globally or per block.

◇

Website projects

A Website Projects post type and case-study block patterns for the client work that doesn't live in a repo.

⛨

Secure by default

Secrets and tokens encrypted at rest, nonces and capability checks everywhere, and least-privilege scopes.

⚡

Drop-in

No build step, no framework. Install the zip, activate, connect — done.

Set up in minutes

Full walkthrough in the OAuth setup guide.

Install & activate. Upload repofolio.zip via Plugins → Add New → Upload.
Create a GitHub OAuth App. Paste the callback URL shown on the settings page into github.com/settings/developers.
Connect. Enter the Client ID & Secret in Settings → Repofolio, then click Connect with GitHub.
Show your work. Add the Repofolio Repo Grid block, and build project pages from the Repofolio patterns.
